# DigitRecogniser

Создано студенческой командой в учебных целях.  
Мы только учимся работать с GitHub.

Программа распознаёт цифры на изображениях размером 28×28 пикселей.  
Датасет собран вручную и включён в файл `nums_book.zip`.  
Не стоит ждать идеального результата.

> ⚠️ Программа собрана с помощью PyInstaller антивирус может посчитать её подозрительной.

## Начало работы

1. Поместите программу в папку например, `test`.
2. Запустите программу — она создаст папку `ImagesForAI`.
3. Сохраните в эту папку изображение в формате PNG размером 28×28 пикселей.
4. В открывшемся терминале нужно выбрать изображение из папки `ImagesForAI` (пункт 1).  
   Выбор делается путём ввода индекса из показанного списка.
5. Через меню введите `2`, чтобы продолжить, — нейросеть попытается распознать ваше изображение.

## Обучение и дообучение

- Функция дообучения пока недоступна (планирую добавить позже).
- Чтобы обучить нейросеть:
  1. Создайте папку `train`.
  2. Поместите в неё изображения.
  3. Запустите скрипт `TnCeAI`.
  4. При необходимости настройте параметры обучения в этом скрипте.
- Для запуска из IDLE откройте файл `main.py`.

---

## Сборка .exe‑файла

Чтобы собрать собственный `.exe`-файл, установите PyInstaller и выполните команду:

pyinstaller --onefile --name=DigitRecogniser --add-data "modelAIV1.pkl;." --icon "t3.ico" main.py
